# PDF 글자 수

교실 도구함의 `열기.cmd`를 실행하고 PDF 글자 수 카드를 선택하세요. 서버 창을 닫으면 로컬 서버가 종료됩니다. PDF 기능은 파일을 직접 더블 클릭하는 방식 대신 localhost 실행이 필요합니다.

PDF와 결과는 브라우저 메모리에서만 처리하며 서버로 전송하거나 브라우저 저장소에 기록하지 않습니다. 라이브러리와 CMap·폰트도 이 폴더에 포함하여 CDN이나 인터넷 연결이 필요하지 않습니다. 로컬 서버는 정적 파일 GET 제공만 담당합니다. 앱은 PDF 안의 스크립트나 링크를 실행하지 않습니다.

공백 포함: NFC 정규화한 코드 포인트 수, 줄바꿈 제외. 공백 제외: 모든 유니코드 공백 제외. 이모지 결합 문자열은 코드 포인트별로 계산합니다. 페이지 구분 문구는 제외합니다. OCR 미지원이며 스캔·혼합 PDF는 실제보다 적게 집계될 수 있습니다. 암호 PDF는 로컬에서 해제한 사본을 사용하세요. 최대 100 MB, 한 번에 한 파일입니다.

PDF.js 6.4.299 (Mozilla, Apache-2.0): `vendor/package/LICENSE`, `vendor/package/README.md` 참고. npm 공식 배포 패키지를 로컬에 포함했습니다.

개인정보 주의: 이 작업 폴더 자체가 OneDrive 아래에 있으므로 소스 폴더는 OS의 OneDrive 설정에 따라 동기화될 수 있습니다. 앱은 선택한 PDF를 이 폴더로 복사하지 않습니다. 원본 PDF가 OneDrive 폴더에 있다면 원본의 동기화 여부는 OneDrive 설정을 따릅니다.
