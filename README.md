# 교실 도구함

GitHub Pages 공개 버전은 교실 타이머와 PDF 글자 수 도구를 제공합니다. PDF는 브라우저 안에서 처리되며 서버에 업로드하지 않습니다.

일기장 코드, 실제 기록, 백업 및 로컬 서버는 공개 저장소와 사이트에 포함하지 않습니다.

## 실행

GitHub Pages 주소를 열거나 정적 HTTP 서버로 이 폴더를 제공하세요. PDF 분석에는 HTTP(S)가 필요합니다. Node.js로 `node timer.test.cjs`를 실행하면 타이머 모델을 검증할 수 있습니다.

PDF.js 6.4.299와 라이선스가 pdf-counter/vendor/package에 포함되어 있습니다.
